# The Deeplicious — GitHub Pages Site

This folder contains a self-contained static website for The Deeplicious restaurant. It can be hosted for free on GitHub Pages.

## Files

- `index.html` — the full webpage with inline CSS
- `hero-shawarma.jpg` — hero image
- `crispy-chicken.jpg` — menu image
- `classic-shawarma.jpg` — menu image
- `shawarma-platter.jpg` — menu image
- `map.jpg` — location map image

## How to host on GitHub Pages

1. Create a new GitHub repository (e.g. `the-deeplicious`).
2. Upload **all files in this folder** to the repository root.
3. Go to **Settings → Pages** in the repository.
4. Under "Build and deployment", select **Deploy from a branch** and choose the branch you uploaded to (usually `main`).
5. Click **Save**. Your site will be live at `https://your-username.github.io/the-deeplicious/` after a minute or two.

## Updating

Edit `index.html` directly to change text, links, or colors. Replace any `.jpg` image with a new file of the same name to update photos without changing the code.
